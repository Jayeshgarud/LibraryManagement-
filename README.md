# Library Management System

## Description
A console-based Library Management System developed in C++ using Object-Oriented Programming concepts. The system manages books and members, supports book issue and return operations, and allows searching books by title or author.

## Features
- Add Book
- View Books
- Add Member
- View Members
- Issue Book
- Return Book
- Search Book by Title
- Search Book by Author

## Technologies Used
- C++
- OOP
- STL Vector

## How to Run
1. Compile the code:
   g++ main.cpp -o library

2. Run:
   ./library
